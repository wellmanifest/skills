# Wellmanifest Skills

Portable standard for governed agent skills, deterministic diagnostic routing
and advisory LLM selection.

This repository owns the data contract for skill definitions and catalogs. It
does not execute agents, grant authority, store credentials, repair products or
merge pull requests. Runtime implementations remain in their product
organizations and adopt this standard by immutable revision.

Normative artifacts will live in `standard/`; architecture and adoption
guidance will live in `docs/`.
